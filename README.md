# Skill Studio

**AI Skills 研究与可视化中心**

## 项目定位

这是一个专门用于研究和可视化 AI Skills 的项目，用于：
- 收集和分析各种 AI Skills
- 可视化 skills 结构和关系
- 总结 best practices
- 创建新的 skills

## 目录结构

```
skill_studio/
├── skills收集/      # 从各处收集的 skills
├── 技能分析/        # 分析和解构 skills
├── 可视化/          # Skills 关系图、结构图
├── 模板/           # Skill 创建模板
└── 文档/           # 研究文档和笔记
```

## 使用方式

1. 下载 skills 到 `skills收集/`
2. 用 `技能分析/` 分析结构
3. 在 `可视化/` 创建关系图
4. 用 `模板/` 创建新 skill
